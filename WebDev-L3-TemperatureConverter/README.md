# 🌡 Smart Temperature Lab

A simple and responsive temperature conversion web application built using **HTML, CSS, and JavaScript**.

The application allows users to enter a temperature and instantly convert it between **Celsius, Fahrenheit, and Kelvin**.

## 🚀 Features

* 🌡 Convert between Celsius, Fahrenheit, and Kelvin
* ⚡ Real-time conversion as you type
* 📊 Dynamic temperature indicator bar
* ❌ Validation for invalid temperatures
* 📱 Fully responsive design
* ✨ Modern glassmorphism UI
* 🎨 Gradient background and smooth animations
* 🖥️ Works on desktop, tablet, and mobile devices

## 🛠️ Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling, responsiveness, animations, and glassmorphism design
* **JavaScript** – Temperature conversion and dynamic UI updates

## 🌡️ Conversion Formulas

### Celsius → Fahrenheit

```text
°F = (°C × 9/5) + 32
```

### Celsius → Kelvin

```text
K = °C + 273.15
```

### Fahrenheit → Celsius

```text
°C = (°F - 32) × 5/9
```

### Kelvin → Celsius

```text
°C = K - 273.15
```

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Enter a temperature.
5. Select the input unit.
6. The converted values will be displayed automatically.

## 📱 Responsive Design

The application is optimized for:

* 💻 Desktop
* 📱 Mobile phones
* 📟 Tablets
* Small-screen devices

The layout automatically adjusts according to the screen size.

## ⚠️ Validation

The application checks for:

* Empty input
* Invalid numerical values
* Temperatures below **absolute zero**

If a temperature is below absolute zero, the application displays an error message instead of showing invalid results.
