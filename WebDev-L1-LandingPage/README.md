# 👟 ShoeBrand — Landing Page

A modern and responsive **ShoeBrand Landing Page** built using **HTML5 and CSS3**.
The website is designed to showcase a fictional sneaker brand with a clean product-focused layout, attractive sections, and responsive styling.

---

## 🌐 Project Overview

**ShoeBrand** is a static landing page created to demonstrate frontend web development skills using HTML and CSS.

The website includes:

* 🏠 Hero section
* 🧭 Navigation bar
* ⭐ Features section
* 📖 About section
* 👟 Latest Sneakers section
* 💬 Customer Reviews
* 📞 Contact section
* 🔗 Social media footer
* 📱 Responsive design

---

## ✨ Features

### 🧭 Navigation Bar

The navigation bar provides links to the main sections of the website:

* Home
* Features
* About
* Product
* Reviews
* Contact

The navbar uses `position: sticky` so it remains visible while scrolling.

---

### 🦸 Hero Section

The hero section introduces the brand with:

> **Step Into Style**

It includes:

* Brand introduction
* Short description
* **Shop Now** call-to-action button
* Full-screen background image
* Dark overlay for better text readability

### ⭐ Why Choose Our Shoes?

The Features section highlights the main benefits of the products:

* **Lightweight** — Ultra-light design for all-day comfort.
* **Durable** — Built with high-quality materials.

Cards include shadows and rounded corners for a modern appearance.

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project

Navigate to the project directory:

```bash
cd ShoeBrand
```

### 3. Run the website

Open:

```text
index.html
```

You can also use **VS Code + Live Server** to run the project locally.
