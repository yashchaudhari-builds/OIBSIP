# OIBSIP — Web Development Internship

This repository contains the projects completed as part of the **Oasis Infobyte (OIBSIP) Web Development Internship**.

The projects focus on building responsive and user-friendly web interfaces using **HTML, CSS, and JavaScript**.

## 📂 Projects

### 1. WebDev-L1 — Landing Page

A responsive landing page designed to demonstrate frontend layout, styling, and responsive design skills.

**Technologies:**

* HTML5
* CSS3

**Features:**

* Responsive layout
* Navigation bar
* Hero section
* Product/content sections
* Footer
* Modern UI design

---

### 2. WebDev-L2 — Personal Portfolio

A personal portfolio website showcasing my profile, technical skills, projects, and contact information.

**Technologies:**

* HTML5
* CSS3
* JavaScript

**Sections:**

* Home
* About Me
* Skills
* Projects
* Contact

---

### 3. WebDev-L3 — Temperature Converter

A simple and responsive temperature conversion tool that allows users to convert temperatures between different units.

**Technologies:**

* HTML5
* CSS3
* JavaScript

**Features:**

* Celsius conversion
* Fahrenheit conversion
* User-friendly interface
* Responsive design
* Instant conversion
